Хотели когда-нибудь что-то создать, но не знали с чего начать? Как у писателей бывает "творческий кризис", так и у разработчиков случаются подобные моменты. Этот список призван решить эту проблему раз и навсегда! 👍

Эти проекты:

- Отлично подходят для прокачки навыков программирования :muscle:;
- Отличны для экспериментов с новыми технологиями 🆕;
- Идеальны для портфолио, чтобы впечатлить работодателя или клиента :file_folder:;
- Подходят как примеры для туториалов (статей или видео) :page_with_curl:;
- Легко реализуемы и легко расширяемы новыми фичами :ok_hand:;

Это не просто список, а коллекция с подробным описанием каждого проекта, чтобы вы могли реализовать его с нуля!

Каждый проект содержит:

1. Чёткую и понятную цель;
2. Список _User Stories_ (пользовательских историй), которые стоит реализовать (это скорее рекомендации, а не строгий список задач. Добавляйте свои истории, если хотите);
3. Список бонусных фич, которые не только улучшают проект, но и ваши навыки (по желанию, после выполнения основных задач);
4. Все необходимые ресурсы и ссылки для успешного завершения проекта.

## Проекты 🚀

Проекты делятся на три уровня сложности в зависимости от знаний и опыта.

| Уровень | Профиль разработчика |
| :--: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  1   | Новички, только начинающие путь в программировании. Обычно фокусируются на пользовательских приложениях. |
|  2   | Разработчики со средним опытом. Уверенно работают с UI/UX, инструментами разработки, используют API. |
|  3   | Продвинутые разработчики, осваивающие бэкенд и базы данных. |
